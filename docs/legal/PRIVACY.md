# 快看视频 QuickVideo 隐私说明（MVP 草案）

更新日期：2026-07-21

快看视频 QuickVideo 是一款在 macOS 本地运行的视频知识整理工具。本说明适用于当前个人测试版本；公开销售前应由适用法域的专业人士复核。

## 本地保存的数据

应用在本机 SQLite 数据库中保存任务标题、来源、时长、字幕来源、处理状态、字幕文本、结构化笔记、用户偏好和模型服务 API Key。API Key 以明文保存在本机应用数据库中，不会写入导出的笔记文件，也不会发送到本应用的服务器。为便于排查模型问题，应用会保留最近 30 条调用的时间、模型名、服务地址、用途、耗时、结果状态、请求头、请求参数与完整响应内容；其中 Authorization 中的 API Key 会被遮蔽，但请求正文可能包含字幕与 Prompt。

本地语音转写在设备上通过 whisper.cpp 执行。默认会在任务完成后删除临时音频、字幕中间文件；用户可以在设置中关闭该清理选项。

## 何时会发送数据到网络

- 用户主动下载本地转写模型时，应用会从 whisper.cpp 官方模型仓库下载模型文件。
- 用户主动分析链接时，应用会与 YouTube 或 Bilibili 的公开可访问内容端点交互，以取得可用字幕，或在无字幕时临时取得可处理音频。
- 用户配置并使用自己的 SiliconFlow API Key 时，应用会将字幕文本发送到固定的 SiliconFlow API 地址，以生成摘要。该请求受用户与 SiliconFlow 之间的条款和隐私政策约束。

应用不运营自己的云端账户、分析服务、遥测或广告系统。

## 导出与删除

用户选择导出 Markdown 时，应用仅将任务元数据、摘要和字幕写入用户指定的本地位置。用户可在设置中清空本地资料库；该操作会删除任务、字幕和笔记，但不会删除原始本地视频文件。
